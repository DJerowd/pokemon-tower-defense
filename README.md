# Pokémon Tower Defense

Projeto de estudo e desenvolvimento de um jogo Tower Defense com inspiração no universo Pokémon, desenvolvido no Godot Engine 4 com GDScript.

## Sobre o projeto

O objetivo é criar um jogo com cenário 3D e personagens representados por sprites 2D, com sistemas de combate, ondas de inimigos, posicionamento de unidades, escolha de Pokémon inicial e captura de adversários elegíveis.

Este projeto também tem como objetivo estudar arquitetura de software para jogos, organização de recursos, programação orientada a objetos e desenvolvimento colaborativo.

## Tecnologias

- Godot Engine 4
- GDScript
- Git
- GitHub

## Como executar

1. Instale uma versão compatível do Godot Engine 4.
2. Clone ou baixe este repositório.
3. Abra o Godot.
4. Importe o projeto selecionando o arquivo `project.godot`.
5. Execute o projeto pelo editor.

Consulte a versão recomendada do Godot e os requisitos atualizados antes de executar o jogo.
